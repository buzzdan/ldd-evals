# ts-react-mini

## Commands

- `task build` — type-check and build the bundle
- `task test` — run the unit tests
- `task lint` — tsc, eslint, prettier --check
- `task lintwithfix` — eslint --fix, then prettier --write

React 18, TypeScript strict, Vite. Tests are colocated (`X.test.tsx` beside `X.tsx`).
